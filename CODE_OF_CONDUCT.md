# Code of conduct

Be kind, be specific, assume good faith. Criticise work, not people. No harassment, no discrimination, no personal attacks —
here or anywhere the project gathers.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
If someone's behaviour makes it hard for you to take part, tell the maintainers through the repository's private reporting
channel; it will be handled discreetly.
